Version history

What changed in each release.

  1. v1.0.1 13 November 2026

    • Maximizing or restoring the window no longer breaks into blocks while it redraws
    • Select many steps at once: drag over them, Shift/Ctrl+click, or Ctrl+A
    • Delete key removes the selected steps
    See v1.0.1 on GitHub

  2. v1.0.0 12 November 2026

    • First release: records clicks and keys and replays them inside one app in the background
    • Repeat a set number of times or run for a set time, with countdown and humanize
    • Global hotkeys, tray mode, light and dark themes
    • Tells you when a new version is out and updates in one click
    See v1.0.0 on GitHub

Updating

Download the new installer and run it over the old version. Your settings, hotkeys and saved macros stay where they are.

System requirements

Windows 10 or 11, 64-bit. About 60 MB of disk space. No Python or other software needed.

Code signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.
