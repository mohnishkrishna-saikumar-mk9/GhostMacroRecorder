Is Ghost Macro Recorder free?

Yes. It is free and open source under the MIT licence. There is no account, no advert and no paid version.

Why does Windows block the installer?

New apps that are not code-signed yet are stopped by Smart App Control, and SmartScreen may warn about them. See Windows blocked the installer at the end of this page.

Does it work in games?

Many games ignore background input. Switch Settings, Play to Foreground, which moves the real mouse and keys, and keep the game window in front.

Can it control apps run as administrator?

Only when Ghost also runs as administrator. Windows blocks input from normal apps to apps that run with admin rights.

Why doesn't a hotkey work?

Another program owns that key. Settings, Keys marks it as taken; click the warning to switch to a free key, or click the box and press a different key.

Does it send my data anywhere?

No. Ghost has no telemetry. Its only network request is an optional daily update check to GitHub, which sends nothing about you (switch it off in Settings → App). It only listens to input while you record and never records password fields.

Where are my macros saved?

As .json files in %APPDATA%\GhostMacroRecorder\macros. Settings, App, Open macros folder takes you there.

How do I update to a new version?

From version 1.0.2, Ghost tells you itself: a bar appears at the bottom of the app (and a tray message) when a new version is out. Click Update now and it downloads, installs and reopens. You can also use Settings → App → Check for updates, or download the newest installer from the Releases page. Settings and macros stay.

How do I uninstall it?

Windows Settings, Apps, Installed apps, Ghost Macro Recorder, Uninstall. Your saved macros stay in AppData in case you reinstall.

Can I run it from source instead?

Yes. Install Python 3.10 or newer, download the code from GitHub and double-click install_and_run.bat.

Windows blocked the installer?

SmartScreen ("Windows protected your PC"): click More info, then Run anyway.

Smart App Control blocks new apps that are not code-signed yet, with no button to continue. Code signing for Ghost is being set up. Until then, run it from its source:

git clone https://github.com/mohnishkrishna-saikumar-mk9/GhostMacroRecorder.git
cd GhostMacroRecorder
install_and_run.bat
