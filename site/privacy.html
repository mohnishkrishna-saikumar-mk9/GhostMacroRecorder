Privacy

Last updated 12 November 2026.

The app

Ghost Macro Recorder works offline. It has no network code, analytics or telemetry, and it never sends your recordings, settings or anything else to us or to anyone.

  • It listens to the mouse and keyboard only while you are recording.
  • It skips password fields and Windows security prompts.
  • Settings and saved macros stay on your PC, in %APPDATA%\GhostMacroRecorder.

This website

This site sets no cookies and runs no analytics. To show the latest version and release notes, your browser asks GitHub's public API for them; GitHub sees that request as it would any visit. Fonts load from Google Fonts. The site is hosted on Cloudflare Pages, which keeps standard server logs.

Downloads

Installers are downloaded from GitHub Releases, under GitHub's own privacy statement.
